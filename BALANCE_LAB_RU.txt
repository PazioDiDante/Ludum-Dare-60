ЛАБОРАТОРИЯ БАЛАНСА
F6 на столе открывает отдельную комнату rm_balance. F6 / «К игре» возвращает на стол. Игровая комната сохраняется; лаборатория не меняет инвентарь, деньги и случайную последовательность игры.

Вкладки: Заказ (база, min/max по 8 характеристикам, min/max модулей, OFF), Модули (создать/удалить, имя, начальное количество, вес выпадения, 8 характеристик), Экономика, Результаты.
Клик по полю — ввод. Ctrl+A очищает поле, Enter применяет, Esc отменяет ввод. Пустые min/max означают отсутствие ограничения. Все числа — с точкой, а не запятой. Вес выпадения 0 исключает тип из случайной добычи, но начальный запас остаётся доступен. Удаление типа удаляет его из эксперимента.
Сохранить/Загрузить — balance_settings.json в стандартной папке сохранений GameMaker. Между заходами в лабораторию значения сохраняются в памяти. Сброс требует повторного нажатия.

Комбинации: порядок установки не учитывается; каждый набор количеств считается один раз (при OFF дополнительно учитываются количества включённых модулей). Числа для текущего запаса используют поле «Есть в начале». Для будущего выпадения берётся до slots копий каждого выпадающего типа; невыпадающий тип ограничен начальным запасом. Минимум и максимум характеристик включительны. Геометрия, провода и нелинейные эффекты не моделируются.

Один прогон — один большой заказ. Вначале проверяется стартовый запас. Если денег хватает на случайную полную пачку (по умолчанию 3–4), она покупается целиком. Иначе покупается один девайс; если не хватает даже на него, кнопка денег нажимается до нужной суммы. Затем девайсы разбираются по одному, каждый даёт случайные 2–3 модуля (диапазон настраивается), с повторами и относительными весами. После каждого разбора ищется подходящий набор. Детали копятся. Корпус идёт в утиль, дохода после разбора нет.
При успехе подходящие детали расходуются, добавляется время сборки и награда заказа. Если заказ найден посреди пачки, остальные девайсы остаются купленными, но не разбираются. Итоговый кошелёк включает доход от кнопки и награду; это НЕ прибыль только от заказа.
Цена починенного девайса и время отдельного ремонта используются для сравнения: (цена продажи - цена покупки) / время ремонта. Это грубый показатель без стоимости деталей; ремонт не входит в автоматические прогоны.

Результаты: число комбинаций, доля успехов, среднее/медиана/P90/минимум/максимум времени успешных прогонов, покупки/разборы/нажатия/затраты/кошелёк. Неуспех до лимита устройств не доказывает математическую невозможность. Среднее по успехам при неполной доле успехов смещено, о чём интерфейс предупреждает. Если подходящих наборов нет даже с будущими выпадениями, заказ недостижим в модели.
Перебор и симуляция выполняются порциями; «Остановить» прерывает расчёт. 300000 узлов или 30000 рецептов — ограничение перебора; при достижении числа частичные, симуляция не запускается. Число прогонов, seed и лимит разборов настраиваются. Вычисления используют собственный генератор случайных чисел. Новые настройки действуют после «Рассчитать».

Код: scr_balance — предоставленный исходный расчёт, сохранён без изменений; scr_balance_model — проверка настроек, порционный перебор и симуляция; scr_balance_ui — UI; obj_balance_lab — события комнаты. Максимум 40 типов и 8 слотов установлен для контролируемого перебора.

Названия: при открытии лаборатории и загрузке JSON игровые модули с object_name получают актуальное имя из Create. Меняются только имена: настроенные характеристики, выпадение, запасы, цель и экономика сохраняются. Собственные модули без object_name сохраняют свои названия. Для русских названий в списках, полях и анализе автоматически используется Arial с кириллицей; английский интерфейс сохраняет пиксельный Edit Undo. Старый файл настроек не перезаписывается автоматически.

Переходники — отдельный бонус игры: 33% на один дополнительный случайный переходник при открытии девайса после третьего заказа. В обычном пуле их вес равен 0, чтобы не заменять другие модули. Справка вкладки Modules объясняет бонус. Старая настройка веса 0.5 у переходников обновляется в памяти при загрузке; остальные параметры эксперимента сохраняются. Числовая модель лаборатории не симулирует бонусные переходники и типы проводов.
