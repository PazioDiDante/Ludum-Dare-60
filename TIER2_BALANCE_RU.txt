БОЛЬШОЙ ЗАКАЗ
Объект: obj_big_order. Данные шаблона: orders_tier2_definition() в scr_orders.
Энергия: 3..7; тепло: 0..5; стабильность: 0..5; скорость: 2..5.
Обе границы включены. Ограничений веса, эффективности, точности и износа нет.
База всех характеристик: 0. Награда: 300 монет.
Начиная с четвёртого заказа этот шаблон повторяется без случайной смены требований.
Режим fixed_tier2 включён; фоновый генератор предыдущей версии сейчас не запускается.
Графика платы/корпуса/миниатюры — существующий комплект дрона.

Скорость и эффективность считаются для запитанных модулей, как энергия/тепло/стабильность.
Отключённые модули сохраняют только вес. Для сдачи обязательна замкнутая цепь.
В интерфейсе новые характеристики обозначены SPD и EFF, со знаком и цветом эффекта.
Лаборатория F6 читает все 14 типов через game_module_types(). При открытии
старого эксперимента недостающие новые модули добавляются без сброса настроек.
Если такие модули уже созданы вручную с теми же именами, они не дублируются.
Пользовательские JSON не перезаписываются автоматически.

Исходная копия включена как datafiles/tier2_balance.json для проверки происхождения.
При импорте из неё использованы только шесть новых модулей и границы заказа.
Старые игровые Create, остатки инвентаря и экономика из экспериментального JSON не заменялись.
Изменение JSON после импорта само по себе не меняет игровые параметры: правьте Create
модулей и orders_tier2_definition() либо попросите повторно импортировать настройки.
