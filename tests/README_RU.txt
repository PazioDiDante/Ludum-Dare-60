ПРОВЕРКИ РЕЛИЗА

Тестовые GML-файлы не подключены к Base Game.yyp и не попадают в игру.
Текущий результат: release_results.txt; история проекта: ../VALIDATION_RU.txt.

scr_release_tests.gml проверяет обычный старт, отсутствие отладочного состояния,
реальное размещение деталей и типизированные соединения, требования и оплату
всех шести отдельных заказов и двух повторяющихся заказов второго уровня.
Старые объединённые тесты прототипа, лабораторий и случайного генератора удалены.

ДЛЯ ПОВТОРЕНИЯ
1. Сделайте отдельную копию проекта.
2. Добавьте нужный tests/scr_*_tests.gml как Script. Если используются общие
   функции, добавьте scr_test_helpers.gml; assembler_tests также использует
   recycler_test_feed из scr_recycler_tests.gml, adapter_bonus_tests —
   adapter_ports из scr_adapter_tests.gml.
3. После инициализации obj_game, например на пятом Begin Step, вызовите нужную
   функцию теста. Для релизной последовательности это release_tests().
4. Тесты меняют сцену и могут завершать игру. Не подключайте их к основной копии.

Функции, нужные только проверкам старых координат интерфейса и ширины текста,
перенесены в scr_test_helpers.gml; игровой код их не содержит.
Фоновый прогон требует обхода проверки фокуса в отдельной копии obj_game.
Для проверки звука окно должно иметь фокус; при скрытом прогоне обход проверки
window_has_focus требуется также только в копии scr_audio.
Остальные старые самостоятельные тесты проверяют отдельные механики; их
ожидания могут относиться к прежним настройкам. Успешный список текущего
релизного прогона указан в release_results.txt.

scr_playtest_help_tests.gml: playtest_help_tests() проверяет запрет открытия
роботов без питания через плату, стол и панель, отдельное мигание выбранного
робота, паузу, восстановление питания и место для подсказок во всех заказах.
Снимки сохраняются по абсолютному пути из FIRST_ORDERS_OUTPUT.
